# Vandana - Full Stack Software Engineer Portfolio

A personal portfolio website designed and developed to showcase my experience as a Full Stack Software Engineer, selected projects, technical skills, services and interests beyond software development.

🌐 **Live Website:** https://vandana-portfolio.gt.tc/

---

## Overview

This portfolio brings together my experience across backend engineering, full-stack development, APIs, cloud infrastructure, WordPress and AI applications.

The website was designed with a clean, editorial style to present technical experience alongside selected projects and a more personal look at my interests in travel, exploration and photography.

## Design

The website was designed with a minimal editorial aesthetic using:

- Large typography
- Clean spacing
- Rounded image treatments
- Warm neutral backgrounds
- Teal and orange accent colors
- Custom project visuals
- Responsive layouts

The goal was to keep the site professional while allowing some personality through travel and photography.

## Project Visuals

The project section uses custom-created visual representations of selected engineering projects.

These visuals are intentionally generic and do not expose confidential source code, internal architecture diagrams, credentials or proprietary company information.
